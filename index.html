⚙️ AI 교정 설정 및 API 발급 안내

선택하신 유형에 맞는 최신 사용 가능한 모델을 자동으로 찾아서 연결합니다.

API 키는 이 컴퓨터(브라우저)에만 안전하게 저장되며 서버로 전송되지 않습니다.

🔑 무료 API 키 1분 발급 가이드

  1. Google AI Studio(클릭)에 접속합니다.
  2. 구글 계정으로 로그인합니다.
  3. 화면에서 파란색 [Create API key] 버튼을 누릅니다.
  4. 팝업창에서 Create API key in new project를 선택합니다.
  5. AIzaSy... 로 시작하는 긴 텍스트(API 키)가 생성되면 [Copy]를 눌러 복사합니다.
  6. 왼쪽 'Gemini API 키 입력' 칸에 붙여넣고 [저장하기]를 누르면 완료됩니다!

📖 사용 설명서

📌 기본 사용법

  1. 상단 탭에서 점검하고자 하는 항목(행발, 창체, 교과세특 등)을 선택합니다.
  2. 안내된 나이스 다운로드 경로를 참고하여 엑셀(.xls) 파일을 다운로드합니다.
  3. 다운로드한 엑셀 파일을 화면 가운데 점선 영역으로 드래그하거나 클릭하여 업로드합니다.
  4. 문제가 발견된 학생은 자동으로 붉은색 배경과 함께 강조 표시됩니다.

✨ AI 정밀 검토 사용법 (고급)

Gemini AI를 연결하여 기재유의어뿐만 아니라 문맥상 기재가 부적절한 내용을 짚어내고, 더 나은 교정 방향을 추천받을 수 있습니다.

  1. 우측 상단의 [⚙️ AI 설정] 버튼을 누릅니다.
  2. 안내된 링크(Google AI Studio)로 이동하여 무료 API 키를 발급받아 복사합니다.
  3. 설정 창에 키를 붙여넣고 저장합니다.
  4. 파일을 업로드한 뒤, 원하는 학생의 '상세 내용' 칸에 있는 [✨ AI 정밀 검토] 버튼을 누르면 AI가 문맥을 분석하여 즉시 피드백을 제공합니다.
